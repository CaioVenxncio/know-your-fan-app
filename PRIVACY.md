# Privacy Statement

**Know Your Fan is an independent demonstration project that works only with synthetic data.**

- **What we collect:** nothing personal. The app has no registration form, no file uploads, and no
  fields for names, CPF numbers, addresses, or identity documents of real people.
- **What is stored:** only fictional profiles produced by the built-in generator, kept in a local
  SQLite file on the machine running the app. Text typed into the search box or the "name to look
  for" field is used only for the current page view and is never saved.
- **Analytics:** Streamlit usage statistics are disabled in `.streamlit/config.toml`. The hosting
  platform, if any, may keep its own standard access logs.
- **Your responsibility:** do not type real personal information into any field. Any name that
  resembles a real person is coincidental.

Questions can be raised through the repository's issue tracker. Please do not include personal data.
